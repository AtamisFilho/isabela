# 🧒 Au Pair Dashboard — Edição Oficial (v2.5) · PWA

App de controle da jornada Au Pair: **ponto com pausas, planejado × realizado, anotações com fotos, relatórios PDF, backup automático** — 100% offline.

## 📱 Instalar no iPhone
1. Abra o endereço deste site no **Safari**;
2. Botão **Compartilhar** (□↑) → **Adicionar à Tela de Início**;
3. Pronto — ícone próprio, tela cheia e dados salvos no aparelho.

> Veja o guia completo em `INSTRUCOES-iOS.md` e faça backups em Config → Exportar.
